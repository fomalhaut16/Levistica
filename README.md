# Levistica

動画・資料調査・SNSに使うmacOSブラウザです。複数タブ、PDF閲覧、履歴、ブックマーク、ダウンロードに対応しています。

現在は開発中です。Chrome拡張、カメラ・マイク、Discordの通話には対応していません。主要サイトの互換性と実用時のメモリ使用量は検証中です。

## 起動する

macOS 26以降で利用できます。現在はソースから起動します。Xcode 26.6以降とPython 3を用意し、リポジトリのディレクトリで実行してください。

```sh
CONFIGURATION=Release ./script/build_and_run.sh
```

生成されるアプリは `.local/DerivedData/Build/Products/Release/Levistica.app` です。以後はこのアプリをFinderから開けます。

## 基本操作

アドレス欄へURL、ホスト名、検索語を入力し、Returnを押してください。検索語はDuckDuckGoへ送信します。

| 操作 | キー |
|---|---|
| アドレス欄へ移動 | Cmd-L |
| 新しいタブ／タブを閉じる | Cmd-T／Cmd-W |
| 閉じたタブを開き直す | Cmd-Shift-T |
| 前／次のタブ | Cmd-Shift-[／Cmd-Shift-] |
| 戻る／進む | Cmd-[／Cmd-] |
| 再読み込み | Cmd-R |
| ページ内検索 | Cmd-F |
| 拡大／縮小／元の倍率 | Cmd-+／Cmd-−／Cmd-0 |
| ブックマークへ追加 | Cmd-D |
| ブックマーク一覧 | Cmd-Option-B |
| 閲覧履歴 | Cmd-Y |
| PDFを開く／保存 | Cmd-O／Cmd-S |
| 設定／終了 | Cmd-,／Cmd-Q |

左の一覧でタブを検索・並べ替えできます。検索結果からタブを選ぶと検索を解除し、選択したタブを見える位置へ表示します。Commandクリックは背面の別タブ、Command＋Shiftクリックは選択する別タブに開きます。

## タブの保持と休眠

「ページ」メニューやタブの右クリックから「このタブを保持」を選べます。選択中のページは、確認してから手動で休眠できます。入力・再生・転送などの保護対象を検知した場合は休眠しません。検知できない入力や通信もあります。自動休眠は行いません。

休眠からの再開はURLの読み込み直しです。入力、ページ内の履歴、スクロール、動画の再生位置は戻りません。

## 保存と復元

正常終了後はタブの順序と選択を戻し、選択中のページだけを読み込みます。異常終了後は一覧だけを戻し、ページを開くか選べます。閉じたタブやアプリ終了前のフォーム入力は復元しません。

タブ一覧を読めず正常終了時のバックアップがある場合は、日時とタブ数を確認して一覧を復旧できます。元の保存ファイルは残し、ページは選択して開くまで読み込みません。

## 履歴とサイトデータ

設定の「履歴」で、記録の停止・再開と保存期間を変更できます。履歴一覧は名前・URLを入力してReturnで検索し、個別削除や全削除も可能です。

「サイトデータ」では、ドメインごと、またはすべてのCookie・キャッシュ・サイト内の保存データを削除できます。削除するとログアウトする場合があります。履歴、ブックマーク、タブ一覧、保存済みファイルはそのままです。

## ファイルとPDF

ダウンロードは保存先を選び、アプリ下部で進捗・取消・失敗を確認できます。進行中の転送は4件までです。通信断後や再起動後の転送再開には対応していません。サイトへ添付するファイルは、標準ダイアログで選択します。

Web上のPDFはタブ内で閲覧・検索できます。保存にはCmd-Sを押してください。PDFをURLから再取得します。フォーム送信の結果として表示したPDFの再送保存や、PDFへの入力・注釈を反映した保存には対応していません。ローカルPDFはCmd-Oで開き、再起動後はファイルを選び直してください。
